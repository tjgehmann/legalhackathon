## TONE AND STYLE GUIDELINES

All customer-facing communication from TechForward Customer Care must follow these principles:

| Principle | Guidance |
|-----------|----------|
| **Empathy first** | Acknowledge the customer's experience in the first sentence before providing any explanation |
| **No jargon** | Write in plain language. Avoid internal acronyms. If you must reference a contract clause, explain it in plain English alongside the reference |
| **Own it** | If TechForward made a mistake, say so clearly. Avoid passive voice that obscures responsibility ("an error occurred" vs. "we made an error") |
| **Be specific** | Give exact dates, amounts, and reference numbers. Vague responses increase frustration |
| **One clear next step** | Every email should tell the customer exactly what will happen next and when |
| **No empty promises** | Only commit to timelines you can keep. It is better to say "by end of week" than "within 24 hours" if you cannot guarantee 24 hours |
| **Keep it short** | Customers do not want to read essays. Get to the point within 3–4 sentences, then use bullet points for details |
